# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML5 Canvas 和 JavaScript 实现的经典坦克大战游戏，可直接在浏览器中运行。

## 🕹️ 游戏玩法

- 控制你的绿色坦克，消灭所有红色敌方坦克
- 保护地图底部的基地（鹰标志）不被摧毁
- 摧毁砖墙可以开辟新路径，钢墙无法被摧毁
- 收集道具获得增益效果

## 🎯 操作方式

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` 或 `↑` `←` `↓` `→` | 移动坦克 |
| `Space` | 发射子弹 |
| `Enter` | 开始 / 暂停 / 重新开始 |

## ✨ 特性

- 🗺️ **3 种关卡地图**，通关后循环并增加难度
- 🧱 **可破坏砖墙** 和 **不可破坏钢墙**
- 🤖 **AI 敌方坦克**：会追踪玩家并射击
- 💥 **爆炸粒子效果** 和屏幕震动
- 🎵 **8-bit 风格音效**（使用 Web Audio API）
- 🏆 **5 种道具**：
  - 🔵 速度提升 (S) - 移动速度加快
  - 🟡 快速射击 (R) - 射击冷却缩短
  - 🟢 护盾 (🛡) - 短时间内无敌
  - 🔴 额外生命 (❤) - 增加一条命
  - 🔵 冰冻 (❄) - 冻结所有敌人
- 📊 **分数系统**：消灭敌人 +100，摧毁砖墙 +5，通关奖励 +500
- 🌊 **水地形**：坦克无法通过
- 🌲 **森林地形**：视野遮挡

## 🚀 如何运行

1. 克隆仓库：
```bash
git clone https://github.com/YOUR_USERNAME/tank-battle.git
```

2. 直接用浏览器打开 `index.html` 即可游玩！

或者直接在浏览器中打开本地文件，无需任何服务器。

## 🛠️ 技术栈

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API
- 纯 CSS3 动画
